# Project Schedule Templates

Four generalised templates covering the project types we typically run.
Durations in working days. Predecessor column refers to phase IDs in the same template.

---

## Template A — Commercial & Industrial Solar (10–100 kW, ± Battery)

Typical span: 8–16 weeks

```
Phase                                Dur (d)   Predecessor
─────────────────────────────────────────────────────────
1. Initiation
   1.1 Contract award / KO              1
   1.2 Site visit                       2-3      1.1
   1.3 Structural assessment            3-5      1.2
2. Design & Engineering
   2.1 Helioscope / system sizing       3-5      1.2
   2.2 SLD & engineering drawings       3-5      2.1
   2.3 Mount BOM / Electrical BOM       3-5      2.2
3. Approvals (parallel branch)
   3.1 Grid connection application      1        2.3
   3.2 Network approval wait            15-25    3.1
   3.3 Council approval (if required)   5-7      2.3
   3.4 Protection study                 5-7      2.3
4. Procurement (parallel branch)
   4.1 Solar panels                     10-20    2.3
   4.2 Inverters                        10-20    2.3
   4.3 Battery / BESS (if any)          15-25    2.3
   4.4 Mounting / BOS                   7-15     2.3
   4.5 GPU / DEIF / Meters              15-25    2.3
5. Civil & Mounting
   5.1 Site prep / WHS                  1-2      3.3 + 4.4
   5.2 Mark out & install mount         2-4      5.1
   5.3 Cabling / tray runs              3-5      5.2
6. Electrical Installation
   6.1 Panel mounting & DC wiring       3-5      5.3 + 4.1
   6.2 Inverter install                 1-2      6.1 + 4.2
   6.3 AC tie-in & earthing             2-3      6.2
   6.4 Battery install                  2-3      6.3 + 4.3
   6.5 Protection board install         1-2      6.4 + 4.5
7. Commissioning & Testing
   7.1 Power shutdown & meter           1        6.5
   7.2 Monitoring system install        1        7.1
   7.3 Utility witness test             1-3      7.2 + 3.2
   7.4 Commissioning sign-off           1        7.3
8. Handover
   8.1 STC / LGC submission             1-2      7.4
   8.2 As-built & manuals               1-2      7.4
   8.3 Customer training                1        8.2
   8.4 Project close-out                1-2      8.1 + 8.3
```

## Template C — Hybrid Off-Grid (Wind + Solar + Battery)

Typical span: 16–20 weeks

```
Phase                                Dur (d)   Predecessor
─────────────────────────────────────────────────────────
1. Feasibility
   1.1 Wind resource measurement        10-14
   1.2 Solar irradiance & load profile  8-12     1.1
   1.3 Feasibility report               5-7      1.2
2. System Design & Engineering
   2.1 Hybrid architecture              10-12    1.3
   2.2 Component selection              12-15    2.1
   2.3 Engineering drawings             10-12    2.2
3. Approvals (parallel)
   3.1 Council DA & building permits    15-20    2.3
   3.2 Aviation & wildlife clearance    15-20    2.3
   3.3 Grid network agreement           15-20    2.3
4. Procurement
   4.1 Wind turbine                     25-30    2.3
   4.2 Solar panels                     20-25    2.3
   4.3 Battery bank                     20-25    2.3
   4.4 Inverters & charge controllers   12-15    2.3
5. Civil
   5.1 Site preparation & access        7-10     3.1
   5.2 Turbine tower foundation         10-12    5.1
   5.3 Solar array footings & shed      10-12    5.1
6. Wind Turbine Erection
   6.1 Tower assembly                   5-7      5.2 + 4.1
   6.2 Crane lift, nacelle & blades     7-10     6.1
7. Solar Array Installation (parallel with 6)
   7.1 Ground mounts                    5-7      5.3 + 4.2
   7.2 Panel install & wiring           7-10     7.1
8. Battery & Inverter Setup
   8.1 Battery cabinet & racking        5-6      7.2 + 4.3

9. Commissioning & Performance
   9.1 System testing & calibration     5-7      6.2 + 8.3

```

Notes
• Hierarchy: Project (P) ▸ Task (P-T) ▸ Subtask (P-T-S). Edit subtask data; tasks and projects roll up automatically (earliest start, latest end, summed costs).
• Scheduled vs Actual: Scheduled dates are the plan — set when a row is created and only changed by opening the edit modal. Actual dates track what really happened (or is happening). Dragging a bar shifts actual dates only; the schedule stays put as a baseline to measure delay against.
• Predecessors: comma-separated list of IDs that must finish before this one can start (Finish-to-Start). A subtask's status is locked at "Not Started" until every predecessor reaches "Done".
• Buffer (days): how many days a subtask can be delayed without delaying the project end. Buffer = 0 → critical path (★).
• Critical path: the chain of subtasks with Buffer = 0 (★). Any delay on these slips the project finish — focus management attention here.
• Status: only editable on subtasks. Pick one of Not Started / In Progress / Delayed / Done. Tasks and projects roll up by priority (any Delayed → Delayed; else any In Progress → In Progress; else all Done → Done; else Not Started). Picking "Delayed" prompts for a new end date and reschedules downstream tasks.
• Variance = Quoted Cost − (Actual Spend + Committed). Negative means projected overrun.
• Project Margin = Sale Price − Estimated Raw Cost (proposal-stage). Final Margin = Sale Price − (Actual + Committed), locked when every subtask is Done.
• Row grouping: use the ▾/▸ arrows next to project/task rows to collapse subtasks, or "⊟ Collapse" in the toolbar.
• Saving: the CSV download is the session store — reload it next time by attaching the file and re-running the gantt-chart skill.
